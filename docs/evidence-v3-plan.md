# 段落级证据链改造计划

目标：每张卡只有一个明确、可证伪的论点；原文摘录必须逐字回验到具体附件、物理页、PDF 文本段与行框。模型相关性评分不能替代出处验证。

1. 定位：删除短前缀猜测；全文归一化映射保留字符到原始行坐标，检测重复歧义；记录 PDF SHA256、段落 ID、完整原文、偏移及多页 spans。未匹配/歧义不生成高亮。
2. 建卡：模型输出结构化 atomic claims + verbatim quotes + support relation；逐条在检索上下文回验，禁止以整个 chunk 或摘要首句冒充原文/原子论点。失败留诊断，不静默伪造。
3. 持久化：追加可迁移 provenance JSON；旧卡重新定位，不信任旧 exact/fuzzy 缓存；原始论文/检索上下文保留。
4. 打开闭环：动作 ID、租约重投、ack/error、状态查询；协议打开仅代表已派发；多页逐段高亮，错误不能提示成功。
5. 交付：有针对性的合成 PDF 回归（中英、连字符、重复句、跨页、无匹配）；动作重投/回执与建卡验证；打包插件并保留旧包。真实 Zotero 渲染验证与模型端到端任务必须独立标明结果。

不把 PDF 的排版 block 说成语义段落：保存 block/line 身份和原文跨度；多栏、扫描件与复杂公式无法可靠提取时显式待核验。视觉/OCR 回退只有通过同样的出处与坐标验证后才能晋升为可引用证据。

## 已执行与验收边界（2026-11-08）

- 新版抽取链路通过本机 Ollama 的合成实验契约烟测：输出一个原子论点，逐字摘录回验通过。真实文库一篇 PDF 段落定位通过；该段模型返回空证据，未伪造卡片。
- PDF 映射按字符框合并为逐行选区，保留完整排版段、段内偏移、PDF 指纹；跨页 spans 分别建临时注释。重复引文不会根据页码提示擅自选择。
- 去掉跨 Python 版本 site-packages 注入；PDF 依赖缺失时隔离到 PDF 运行环境，避免污染模型进程。
- 新卡没有唯一文献归属或没有原文逐字摘录时拒绝入库。模型原子性与语义支撑关系仍是模型判断，标为待复核；相关性分数不是置信概率。
- 旧卡不删除、不自动改写论点；旧 exact/fuzzy 几何视为失效，打开时重新验证。手动摘录允许未填写论点，但明确显示待整理，不给虚构的 8.5 分。
- 打开请求持久化、30 秒租约、5 分钟重投窗口、执行成功/失败回执；工作台等待执行回执。现有注释会按新坐标更新，修复复用旧错误高亮的问题。
- 旋转页和不能解析文本的扫描件保留待核验，不猜测坐标。OCR/视觉模型回退尚未实现。
- 插件 1.1.0 已打包并备份安装；SearchTools 后端已重启。Zotero 未被关闭，需重启以载入新插件；真实阅读器跳转/高亮/反向建卡仍待用户重启后验收。代码测试不能替代这一实机环节。
- 研究范围先拆成 2–4 个问题仍由 Skill 调用层负责；本次新增的是检索后的原子证据抽取，不代表已建立跨论文的全局论证图或完成扫描件多模态解析。
