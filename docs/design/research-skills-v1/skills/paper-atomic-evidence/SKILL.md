# 论点方法拆解与证据绑定

审核草案：配套 research_* 和部分 cards_* 工具尚未上线。本文件位于设计目录，未安装。数据和工具规格见 [工具契约](../../TOOLS.md)，验证规则见 [总方案](../../PLAN.md)。安装时须迁入包内 references 并更新链接。

## 独立或接续运行

用户直接提供方向、大纲、方法或实验设计时，从该输入新建研究记录并拆句，无须 Skill 1 的运行记录或交接包。联合运行时先由 Skill 1 完成选题，本技能只处理选定方向，保留 direction_id 和交接版本。交接包里的核心证据与复用的历史卡均进入下述二审。

## 输入与原子拆分

接受已有方向/大纲，或第一个技能的 handoff。保留原文、位置和revision；已有交接包也需检查来源哈希、scope 与工具能力，不强制重跑选题。

先拆需求侧 atom，再从文献抽取源命题；两者不可混为一条 claim 字段。

- 一条 atom 只有一个独立主张或方法操作，含对象、条件、比较对象、指标/结果和证据需求；缺信息保留待明确。
- 类型区分背景事实、已报道结果、方法来源、方法步骤、设计选择、研究假设。
- 方法细分为动机、来源、机制/公式、参数、操作和验证；多结果、因果推论与适用范围分别拆开。
- 原创方法和未来实验保留“拟采用/待验证”身份；不寻找一句相似原文就把新假设标为已证实。
- 不设固定2～4个问题上限；按大纲完整拆解，使用稳定ID和依赖关系防止遗漏。

## 确定文献范围

每个 atom 生成主题、方法、条件、指标和反证查询。发现 Zotero 标签/分类后按标题和标签匹配，再补摘要与全文召回；标题/标签只用于相关性筛选。

复用有效历史证据，检查原附件哈希、定位版本和目标语义。文库不足时调用 paper-search，去重并在既有授权内分批导入（每批≤20）；无授权则暂存候选。分别记录缺论文、缺全文、索引失败和证据不足。

冻结显式 scope_revision 和文献版本清单，等待索引就绪；禁止默认用最近项目。调用 PaperQA2 时按 atom 和候选文献子集检索，保留不同文献及反证，避免少数高分卡覆盖所有论点。

## 建卡与绑定

源卡保存一个原文命题、连续原语言quote、上下文、准确文献/附件和所有段落spans。绑定层单独保存 atom↔card 的支持、反驳、限定或不足关系；多卡可支持同一atom，同卡可复用但关系需分别核验。

三个验证分开执行并呈现：

1. 原文：完整quote可在源文本回验，摘要或翻译不能冒充原句。
2. 定位：准确附件/PDF哈希、物理页、印刷页标签、版面段ID、字符偏移、rects；重复摘录不能靠猜页消歧。
3. 语义：对象、条件、比较对象、数值/单位、指标、因果强度和适用范围是否支持目标句；保存结构化判定及理由。

相似度和模型分数只用于排序，不决定支持结论。找到原句不等于目标句成立。限定性证据需修改句子并重核后才计完整支持；相互矛盾的证据并列展示。

实验数字绑定对应实验/表格/消融及设置。表格须含行列、单位和脚注；视觉估读不能伪造为原文段落。不能可靠解析时标待核验。

## PaperQA2 返回后，由当前运行本 Skill 的模型逐项二审

PaperQA2 和下层模型负责召回、抽取、提出初判。当前对话中执行本 Skill 的上层模型负责阅读和裁决。即使两层使用同名模型，也分别记录两次操作。工具只取原文、校验版本和保存上层提交的决定。再次调用 verify_claim 或让后台模型代写审核意见均不能完成此步。

1. 按 atom 分批取回**每个候选绑定**的审查材料。阅读原大纲句、atom 全句、拟引用位置、原语言摘录、来源段及相邻上下文。涉及数字时同时读取对应实验设置、表头、行列、单位、脚注或图例。材料过长用游标续读，材料缺失时退回补取。
2. 先据原文写出它直接证明什么，再与目标 atom 比较。核对研究对象、数据和环境、对照组、指标和数值、因果强度及适用范围。检查源段是作者本人的实验、作者猜想，还是对前作的转述。随后对照下层初判，逐条写下决定、简短理由及所依据的 span ID。
3. 提交关系 supports / qualifies / contradicts / insufficient。可以批准直接支持、保留限定或反证、驳回错配、退回补查。例：仿真段落报告延迟降低，目标句却声称真机能耗降低，应驳回该绑定，并按“真机、能耗、同一方法”补检。若改写成仿真延迟结论，建立新版 atom 重新核验。
4. 对同一 atom 汇总全部正反材料，指出冲突能否用实验条件解释。仍有实质冲突则标 disputed，输出双方原文和可成立的较窄表述。每个返回绑定均记录二审结果或待审状态。预算用尽时保存游标、已审数及待审数。
5. 仅当前版本、出处有效且经上层复核通过的关系可用于对应类型的正式引用。待审、退回或过期项保留在工作台。Reader 手选卡、历史高分卡及交接卡绑定到新 atom 时适用同一规则。若审核工具暂缺，可交付带锚点的本地二审表，并标明尚未写入工作台。

## 双端溯源与反向建卡

用 cards_locate/cards_open/cards_action_status（需先探测能力）或已有等效后端接口完成定位闭环。排队不代表已打开；实际渲染并载入目标高亮后才报告成功。跨页高亮逐span处理。

未验证、附件变化、歧义或OCR映射不可靠时禁用精确高亮，允许明确标注的页级浏览。临时批注保留 `#evidence-temp` 与桥接来源标识；清理限于插件所属临时批注。

Zotero真实选文回传必须携带原始选区并通过附件/文字/坐标回验；绑定用户选择的atom，未选择则进入待整理，不自动挂到最近课题。反向建卡不跳过语义核验。

## 交付

输出原子句子表、句子/方法→atom→binding→card→段落的证据图、可引用措辞、反证和未解决缺口；提供工作台和Zotero入口。只对实际采用的合格卡生成规范引用，笔记写回沿用授权且分别报告成功或失败。

正式支持覆盖率仅统计需外部支撑atom，假设与原创设计另列。正文无支撑处标待验证；不能用相似的论文替代精确支持，也不能删除未匹配句子来提高覆盖率。

配套工具未实现时可用当前接口逐项核查并保存结构化本地产物，但必须明确缺失的批量绑定/持久化/阅读器验收，不虚报完整功能成功。
